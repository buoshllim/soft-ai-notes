# "AI야 나를 알려줘"

SK스퀘어 HR에서 구성원 프로파일 데이터를 보완하기 위해 여러분의 참여를 요청드립니다.

이 데이터는 인재 육성, 커리어 지원, HR 주요 의사결정에 직접 활용됩니다.
**여러분을 조직이 제대로 이해하고, 더 나은 기회를 드리기 위한 기반입니다.**

> 모든 항목에 답하실 필요는 없습니다. **알려주고 싶은 정보만 골라서 제출해 주셔도 됩니다.**

---

## STEP 1. 본인 프로파일 먼저 확인해 주세요

PM시스템에 본인 프로파일을 직접 조회할 수 있는 기능이 생겼습니다.

**PM시스템 접속 → 우측 상단 본인 사진 클릭 → 프로파일 확인**

현재 등록된 정보를 먼저 확인하시고, 누락된 항목이나 수정이 필요한 내용이 있으면 아래 방법으로 알려주세요.

---

## STEP 2. AI로 부족한 부분 채워 주세요

**아래 프롬프트를 복사해서** 본인이 가장 오래·자주 사용해온 AI(Claude, ChatGPT, Gemini 등)에 붙여넣기 하세요.

AI가 그동안의 대화 기록을 바탕으로 먼저 정리해주고, 추측하기 어려운 항목은 직접 물어봅니다.
최종 결과를 아래 두 가지 방법 중 하나로 제출해 주세요.

- **PM시스템** 우측 상단 본인 사진 클릭 → **[문의하기]** 버튼
- **HR 담당자 이메일** 직접 회신

---

## 프롬프트

아래 전체를 복사해서 AI에 붙여넣기 하세요.

```
지금까지 나와 나눈 대화를 토대로, 아래 항목들에 대해 네가 먼저 정리해서 알려줘.
이 내용은 회사에 나의 성장을 지원하기 위한 데이터로 전달될 예정이야.

1. 내가 주로 다루는 업무 영역과 역할·책임 범위
2. 내가 자주 고민하는 문제 유형과 주요 의사결정 사례
3. 내 사고 방식과 커뮤니케이션 스타일
4. 강점으로 보이는 역량
5. 내가 AI에게 자주 도움을 요청하는 영역
6. 5~10년 후 내가 지향할 것 같은 커리어 방향
7. 향후 경험해보고 싶을 것 같은 역할이나 업무 영역
8. 내게 가장 효과적이었거나 효과적일 것 같은 성장방식
9. 지금까지 경력에서 가장 중요했던 경험
10. 더 크고 넓은 역할과 책임을 맡는 것에 대한 내 생각
11. 해외 거주·학업·근무 경험 (유년기~직장 생활 포함)
12. Globality 감각과 외국어 역량

정리가 끝나면 두 가지를 해줘.
- 내용 중 틀리거나 수정하고 싶은 부분이 있으면 내가 다시 알려줄게. 내 얘기를 반영해서 다시 답을 줘.
- 대화 기록만으로 추측하기 어려운 항목이 있으면, 한 개씩 나한테 물어봐줘.
```

---

## 추가로 있으면 꼭 알려주세요

이전 멤버사(SK그룹 내 다른 계열사 포함)에서 **myResume, Self-Profile, 역량 진단 자료** 등을 작성하신 적 있다면 알려주세요.

- 파일을 직접 보유하고 계시다면 함께 제출해 주시면 좋습니다.
- 갖고 계시지 않더라도, 어느 회사의 어떤 양식이었는지만 알려주시면 HR에서 직접 요청해 받도록 하겠습니다.

---

## 참고

- AI를 오래·자주 써온 분일수록 결과가 더 풍부하게 나옵니다.
- 답하기 어렵거나 공유하고 싶지 않은 항목은 건너뛰셔도 됩니다.
- 제출해 주신 정보는 HR 인재 분석 목적으로만 활용되며, 본인의 성장 기회 발굴에 우선 사용됩니다.
