# "AI야 나를 알려줘"

SK스퀘어 HR에서 구성원 프로파일 데이터를 보완하기 위해 여러분의 참여를 요청드립니다.

이 데이터는 인재 육성, 커리어 지원, HR 주요 의사결정에 직접 활용됩니다.
**여러분을 조직이 제대로 이해하고, 더 나은 기회를 드리기 위한 기반입니다.**

> 모든 항목에 답하실 필요는 없습니다. **알려주고 싶은 정보만 골라서 제출해 주셔도 됩니다.**

---

## 참여 방법

**아래 프롬프트를 복사해서** 본인이 가장 오래·자주 사용해온 AI(Claude, ChatGPT, Gemini 등)에 붙여넣기 하세요.

AI가 그동안의 대화 기록을 바탕으로 여러분을 정리해주고, 커리어·글로벌 경험에 대해 질문을 드립니다.
결과를 그대로 복사해서 아래 두 가지 방법 중 하나로 제출해 주세요.

- **PM시스템** 우측 상단 본인 사진 클릭 → **[문의하기]** 버튼
- **HR 담당자 이메일** 직접 회신

---

## 프롬프트

아래 전체를 복사해서 AI에 붙여넣기 하세요.

```
Part 1. 지금까지 함께 나눈 대화와 작업을 돌아보고 아래 항목별로 정리해줘.
(대화 기록이 없거나 적다면 이 파트는 건너뛰고 Part 2부터 진행해줘.)

1. 내가 주로 다루는 업무 영역과 실제 역할 및 책임 범위
2. 내가 자주 고민하는 문제 유형과 주요 판단 및 의사결정 사례
3. 내 사고 방식과 커뮤니케이션 스타일
4. 강점으로 보이는 역량
5. 자주 도움을 요청하는 영역


Part 2. 아래 질문을 한 개씩 물어봐주고 내 답변을 정리해서 요약해줘.

1. 5~10년 후 내가 지향하는 커리어 방향은? (전문가/리더/경영자/미정)
2. 향후 경험해보고 싶은 역할이나 업무 영역은?
3. 가장 효과적이었던 성장방식은? (도전과제/역할확장/멘토링/코칭/교육)
4. 지금까지 경력 전체에서 가장 중요했던 경험은?
5. 지금보다 더 큰 책임을 맡는 것에 대한 나의 생각은? (희망함/시기상조)


Part 3. 아래 질문을 한 개씩 물어봐주고 내 답변을 정리해서 요약해줘.

1. 어린 시절부터 대학교까지, 해외에 거주하거나 공부한 경험이 있어? 있다면 국가·기간·나이대를 알려줘. (대학원 교환학생·어학연수 포함)
2. 직장 생활 중 해외 법인 근무, 글로벌 프로젝트 참여, 장기 해외 출장 경험이 있어?
3. 현재 비즈니스 수준으로 사용할 수 있는 외국어는? 각 언어로 실제 업무한 경험도 알려줘.
4. 해외 경험이 없더라도 국내에서 외국인 동료·파트너와 협업하거나 다문화 환경에서 일한 경험이 있다면 알려줘.
5. 글로벌 또는 다문화 환경에서 일할 때 본인이 잘 발휘하는 강점은?
```

## 추가로 있으면 꼭 알려주세요

이전 멤버사(SK그룹 내 다른 계열사 포함)에서 **myResume, Self-Profile, 역량 진단 자료** 등을 작성하신 적 있다면 알려주세요.

- 파일을 직접 보유하고 계시다면 함께 제출해 주시면 좋습니다.
- 갖고 계시지 않더라도, 어느 회사의 어떤 양식이었는지만 알려주시면 HR에서 직접 요청해 받도록 하겠습니다.

## 참고

- AI를 오래·자주 써온 분일수록 Part 1의 결과가 더 풍부하게 나옵니다.
- Part 2와 3는 AI가 질문을 한 개씩 순서대로 물어보는 방식으로 진행됩니다.
- 답하기 어렵거나 공유하고 싶지 않은 항목은 건너뛰셔도 됩니다.
- 제출해 주신 정보는 HR 인재 분석 목적으로만 활용되며, 본인의 성장 기회 발굴에 우선 사용됩니다.
